# GualbertoOS — Legal Virtual Assistant portfolio

Read **START-HERE.md** for the complete beginner walkthrough. This revision retains the user-selected reference desktop interface and interactions, personalized with résumé-based Legal VA content. See **REFERENCE-NOTES.md** for provenance and intentional differences.

```bash
npm ci
npm run dev
```

Edit `index.html` for profile and app text; `src/desktop.js` for gallery and Terminal answers; `src/desktop.css` for appearance. Build with `npm run build`. Enable GitHub Actions as your GitHub Pages source.

Messages prepares email drafts; it does not deliver messages. Sample files are illustrative, not client work.
