# Reference adaptation

The desktop UI and interaction engine are adapted from the public site selected by the user: https://stucey-rosal.github.io/ (StuceyOS, Stucey Rosal). The reference CSS, wallpaper geometry, icons, window manager, dock effects, menus, Spotlight, Terminal, calendar and settings were retained for close visual and behavioural fidelity. Personal content, metadata, project data, and contact destinations were replaced. The reference site remains owned by its original author; this package does not claim authorship of the reference interface.

Changes required for truthful personalization: legal demonstration gallery, résumé-based skills and credentials, Makati weather, factual toolkit widget, actual supplied portrait, and a message-to-email-draft flow instead of the reference's third-party delivery endpoint. No original author's portrait, project screenshots, contact links, video, or client claims are included.

This retains the reference interface rather than a new theme. Content-specific differences are intentional. Do not describe it as a verified pixel-perfect clone until checking in a browser at matched viewport sizes.
