# Document review checklist

Illustrative administrative template. Not a completed client project or substitute for attorney review.

- [ ] Confirm matter ID and intended document type.
- [ ] Verify names and dates against the approved source.
- [ ] Check numbering, headings, page breaks, and consistent formatting.
- [ ] Compare attachments against the document index.
- [ ] Flag missing information; do not infer facts.
- [ ] Preserve tracked changes and the prior version.
- [ ] Flag citation questions for attorney verification.
- [ ] Check PDF conversion for clipping and missing pages.
- [ ] Confirm permissions and approved recipients before sharing.
- [ ] Obtain attorney approval before filing or sending.
- [ ] Archive the approved version using the team's naming convention.
